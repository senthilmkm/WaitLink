# WaitLink — Live Walk-In Wait Time Publisher

WaitLink is a dead-simple wait-time tracker and publisher designed for walk-in businesses (barbershops, urgent care clinics, pet groomers, auto shops).

## Quick Start
1. Open `index.html` in any web browser.
2. **Desk Mode**: Enter customer name & optional mobile number, then tap **Check In**. When their chair or bay opens up, tap **SERVE NOW** to start service and automatically dispatch a turn-ready SMS text message containing their live ticket tracking link.
3. **Public Link View**: See the live estimate (~20 MINS) that customers see without exposing any customer names.
4. **Window Poster**: Click "Window Poster" tab and tap **Print Window Poster** for a ready-to-hang QR flyer.
